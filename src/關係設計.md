# 一
    Department (部門):{dept_id (PK)
    name
    director_name
    deputy_director_name
    doc_count
    nurse_count}

    Doctor:{doc_id (PK)
    name
    dob
    phone
    address
    history
    dept_id (FK → Department)
    titleVARCHAR(50)職稱}

    Nurse:{nurse_id (PK)
    name
    dob
    phone
    address
    dept_id (FK → Department)
    titleVARCHAR(50)職稱}

    Patient:{patient_id (PK)
    name
    dob
    phone
    address
    subject (病歷摘要/過敏史等)}

    Appointment:{appointment_id (PK)
    patient_id (FK → Patient)
    doc_id (FK → Doctor)
    appointment_time
    item (看診項目)
    status}

    MedicalRecord:{record_id (PK)
    patient_id (FK → Patient)
    doc_id (FK → Doctor)
    result
    prescription_rule (開藥細則)
    record_date}

    Medication:{med_id (PK)
    name
    stock
    threshold
    update_time}

    Prescription:{prescription_id (PK)
    record_id (FK → MedicalRecord)
    med_id (FK → Medication)
    dosage
    quantity}

    Expense:{expense_id (PK)
    patient_id (FK → Patient)
    item (看診項目)
    amount
    create_time
    paid_time}

    Admin:{admin_id,VARCHAR(10),主鍵
    name,VARCHAR(50),姓名
    username,VARCHAR(50),登入帳號（唯一）
    password_hash,VARCHAR(255),密碼（建議存雜湊值）
    phone,VARCHAR(20),電話
    email,VARCHAR(100),信箱
    created_at,DATETIME,建立時間
    is_active,TINYINT(1),是否啟用（1=啟用）}

# 二
    關係,基數,說明
    Department → Doctor,1 : N,一個部門有多位醫生
    Department → Nurse,1 : N,一個部門有多位護士
    Patient → Appointment,1 : N,一個病人可有多次預約
    Doctor → Appointment,1 : N,一個醫生可有多次預約
    Patient → MedicalRecord,1 : N,一個病人可有多筆病歷
    Doctor → MedicalRecord,1 : N,一個醫生可開多筆病歷
    MedicalRecord → Prescription,1 : N,一筆病歷可開多種藥
    Medication → Prescription,1 : N,一種藥可出現在多張處方
    Patient → Expense,1 : N,一個病人可有多筆帳務

## 醫生職稱範例：
    一般牙科醫生
    矯正牙科醫生
    實習醫生
    主任
    拔牙醫生（或口腔外科醫生）
    植牙專科醫生
    兒童牙科醫生

## 護士職稱範例：
    一般牙醫助理
    矯正牙醫助理
    櫃檯護士
    消毒助理
    手術室助理

## admin 權限職責：
    管理  Doctor（1 : N，業務權限）
    管理  Nurse （1 : N，業務權限）
